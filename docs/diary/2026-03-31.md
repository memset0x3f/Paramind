# 2026-03-31

## Summary
今天把 cluster planning / coordinator / inventory 这条“原本挂在 inference 下面”的调度线抽成了顶层并列的 `scheduler/` 模块，并同步把大部分原来放在 `test/p2p/` 里的非 transport 测试迁移到了 `test/scheduler/` 和 `test/inference/`。同时收口了根目录 `Makefile` 的测试入口：保留 `test-inference` / `test-backend`，新增 `test-scheduler` / `test-p2p`，并删除不再可信的 `p2p-demo`。

## Decisions made
这次的核心决定不是“给 inference 加一个子目录”，而是把 `scheduler/` 提升成与 `inference/` 并列的一层。理由很直接：placement、replan、coordinator、hardware snapshot 这些职责已经不再像“推理执行的附件”，它们本质上是独立的调度系统。相应地，`inference/` 只保留 shard loading、本地执行、runtime lifecycle；`scheduler/` 只保留节点画像、分配、replan、cluster-level orchestration；`p2p/` 则暂时继续只承载 transport。

另一个决定是，默认的 `make test-inference` 不再把名字里带 `llama` 的测试算进本地 gate。原因不是这些测试不重要，而是它们依赖 Hugging Face token，不适合作为当前仓库的默认本地入口；需要完整验证时再单独跑。
