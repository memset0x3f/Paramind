## Desktop frontend test matrix

### Fast path — default for UI work
- `make test-frontend-fast`
- Covers:
  - pure chat state reducers and view-model helpers
  - renderer harness behavior in Node
  - browser automation against the harness with Playwright
- Does **not** launch Electron.

### Smoke path — only when Electron/backends matter
- `make test-frontend-smoke`
- Covers:
  - desktop backend bootstrap guarantees
  - global-vs-conversation event routing boundaries
  - inference runner startup path
- Use this when changing preload wiring, backend payload shape, or final integration behavior.

### Harness usage
- `make open-frontend-harness`
- Serves the harness at `http://127.0.0.1:4173/dev_harness.html?harness=1`
- Useful for manual debugging of:
  - left sidebar patching
  - DM request / accept lifecycle
  - AI draft publish behavior
  - preview truncation and ordering
