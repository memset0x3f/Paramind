# 2026-04-01

## Summary

Desktop packaging runtime was refactored away from development-only assumptions. The Electron shell no longer depends on `.venv`, repo-root-relative coordinator startup, or `paramind.apps.desktop.python...` import strings to launch the desktop backend in packaged mode.

## Decisions made

- Chose a **portable Python + desktop-local package root** layout for desktop packaging.
- Standardized packaged runtime resources on:
  - `python-dist/`
  - `python/`
- Kept desktop development flow working by supporting both:
  - dev mode: `__dirname`
  - packaged mode: `process.resourcesPath`

## Evidence / verification

- Added Node packaging tests covering runtime path resolution and `package.json` resource shape.
- Added Python smoke tests covering desktop entrypoint imports without repo package-path dependencies.
- Verified desktop backend entrypoints now avoid `paramind.apps.desktop.python...` strings in the entrypoint files.
